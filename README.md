# farzad-portfolio

Professional home page for **farzadvaziri.com**, hosted on GitHub Pages.

## Files

```
index.html          the whole page: layout, styles and the editable lists
CNAME               custom domain (farzadvaziri.com)
.nojekyll           serve files as-is
assets/previews/    project preview images / GIFs
assets/samples/     featured-sample images, GIFs, small HTML charts
```

## Editing

- **Projects:** in `index.html`, find the `PROJECTS` list near the bottom.
  One line per project. To launch one, set `status: "live"` and fill in
  `problem`, `did`, `result`, `preview` and `links`.
- **Featured samples:** the `SAMPLES` list just below `PROJECTS`.
- **Unconfirmed facts:** search the file for `[[` before publishing.
- **Contact links:** LinkedIn, GitHub and Kaggle are switched off. Each has
  a comment above it showing how to turn it on.

Preview locally by double-clicking `index.html`.
